Pengaturan Menu Portal & Kebijakan Pengawasan

Atur visibilitas tombol Portal Guru, pencetakan bukti ujian, dan batas pelanggaran pindah tab selama ujian.

Jika diisi angka > 0 (misal 3), ujian siswa otomatis dikumpulkan saat mencapai batas pelanggaran tersebut.

Keamanan Akses Operator, Siswa & Guru

Atur PIN masuk Administrator serta pintasan pengelolaan kode akses peserta dan pendidik.

Kode akses siswa per kelas diatur pada tab Kode Siswa.
Kode akses individual guru dikelola pada tab Kode Guru.

Cadangan Data (Backup / Restore) & Pemeliharaan Sistem

Ekspor atau pulihkan seluruh database sekolah (identitas web, kelas, kode akses, jadwal, bank soal seluruh mapel, dan rekap nilai).

Backup Lengkap Database (.json) Unduh seluruh data pengaturan dan bank soal ke perangkat sebagai arsip cadangan.
Pulihkan Data dari Backup (.json) Muat file arsip cadangan sistem untuk menyalin data ujian ke perangkat ini.
